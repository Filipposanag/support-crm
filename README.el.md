# Support CRM

[English](README.md) · **Ελληνικά**

Desktop CRM για Windows, για επιχειρήσεις απομακρυσμένης υποστήριξης IT: διαχείριση πελατών, καταγραφή συνεδριών RustDesk και τηλεφωνικής υποστήριξης με ενσωματωμένο χρονόμετρο, πώληση προπληρωμένων πακέτων ωρών, και έκδοση αποδείξεων και τιμολογίων σε PDF — όλα πάνω σε βάση MariaDB/MySQL.

Φτιαγμένο με **Python 3.11**, **PySide6 (Qt 6)** και **MariaDB**. Το περιβάλλον είναι δίγλωσσο (Ελληνικά / Αγγλικά).

> Αναπτύχθηκε ως πτυχιακή εργασία.

---

## Λειτουργίες

**Πελάτες & απομακρυσμένη υποστήριξη**
- Καρτέλες πελατών (ιδιώτες και επιχειρήσεις, με ΑΦΜ) και ιστορικό ανά πελάτη
- Σύνδεση με ένα κλικ μέσω **RustDesk** (εκκινεί τον τοπικό RustDesk client με το ID του πελάτη)
- Συνεδρίες υποστήριξης με ζωντανό χρονόμετρο, ανάθεση τεχνικού και τύπο συνεδρίας (RustDesk / τηλεφωνική)

**Χρέωση**
- Ωριαία χρέωση με βάση τη διάρκεια της συνεδρίας
- Προπληρωμένα **πακέτα υποστήριξης** (ώρες, τιμή, εκπτώσεις, λήξη) με αυτόματη αφαίρεση των ωρών που χρησιμοποιήθηκαν
- Διαχείριση υπέρβασης: όταν εξαντληθεί ή λήξει ένα πακέτο, ο υπόλοιπος χρόνος χρεώνεται ωριαία ως οφειλή
- Πληρωμές, μερικές πληρωμές και οθόνη **οφειλών** ανά πελάτη
- Οθόνη **λήξεων πακέτων** με προαιρετικό email υπενθύμισης

**Παραστατικά**
- **Αποδείξεις και τιμολόγια** σε PDF (ReportLab) με ανάλυση ΦΠΑ, αυτόματη αρίθμηση και αποθήκευση ανά τύπο
- Οπτικός **επεξεργαστής προτύπων PDF** (πεδία με drag-and-drop, πλέγμα, ζουμ)
- Αποστολή παραστατικού στον πελάτη με email (ρυθμίσεις SMTP μέσα στην εφαρμογή)

**Αναφορές**
- Dashboard με κάρτες KPI, γράφημα εσόδων 6 μηνών και πίνακες ειδοποιήσεων
- Οικονομικές αναφορές ανά περίοδο, με εξαγωγή σε Excel
- Dashboard **απόδοσης τεχνικών** (συνεδρίες, ώρες, μέση διάρκεια, πελάτες, χρεώσεις)

**Διαχείριση**
- Σύνδεση χρηστών με κωδικούς κρυπτογραφημένους με bcrypt
- Ρόλοι και δικαιώματα: **Διαχειριστές** και **Τεχνικοί**, με checklist δικαιωμάτων ανά χρήστη
- **Audit log** των αλλαγών στη βάση
- **Backup & restore** βάσης (καθαρή Python μέσω PyMySQL) με αυτόματο ημερήσιο backup
- Migrations σχήματος από *Ρυθμίσεις → Συντήρηση*
- Εισαγωγή δεδομένων από CSV (με προεπισκόπηση και υποστήριξη ελληνικής κωδικοποίησης `cp1253`)
- Αυτόνομο εργαλείο **configurator** βάσης για την πρώτη εγκατάσταση
- Έλεγχος ενημερώσεων και επικύρωση άδειας χρήσης μέσω απομακρυσμένου endpoint

## Τεχνολογίες

| Τομέας | Τεχνολογία |
|---|---|
| Γλώσσα | Python 3.11 |
| GUI | PySide6 (Qt 6), custom QSS, SVG εικονίδια |
| Βάση | MariaDB / MySQL μέσω PyMySQL (ο configurator χρησιμοποιεί `mysql-connector-python`) |
| PDF | ReportLab (γραμματοσειρές DejaVu Sans για ελληνικά) |
| Excel | openpyxl |
| Ασφάλεια | bcrypt, πίνακες ρόλων/δικαιωμάτων |
| Απομακρυσμένη πρόσβαση | RustDesk (εξωτερικός client) |
| Δίκτυο | requests (ενημερώσεις, επικύρωση άδειας) |
| Packaging | Nuitka + NSIS installer |
| Server | Μικρό PHP endpoint επικύρωσης άδειας (`server_files/`) |

## Αρχιτεκτονική

Ο κώδικας ακολουθεί επίπεδη (layered) δομή:

```
UI (PySide6 views & dialogs)  →  Services (επιχειρησιακή λογική)  →  Repositories  →  MariaDB
```

Η δομή των φακέλων περιγράφεται στο αγγλικό [README](README.md#architecture).

## Εκκίνηση

### Προϋποθέσεις
- Windows 10/11
- Python 3.11
- MariaDB (ή MySQL)
- [RustDesk](https://rustdesk.com/) εγκατεστημένο (για τις απομακρυσμένες συνεδρίες)

### Εγκατάσταση

```bash
git clone https://github.com/Filipposanag/support-crm.git
cd support-crm

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### Ρύθμιση βάσης

Επιλογή Α — configurator (προτεινόμενη):

```bash
python configurator_main.py
```

Ο configurator αποθηκεύει τη σύνδεση στο `config/db_config.json`, δημιουργεί τη βάση και φορτώνει το `db/schema_consolidated.sql`.

Επιλογή Β — χειροκίνητα:

1. Αντίγραψε το `config/db_config.example.json` σε `config/db_config.json` και συμπλήρωσε τα στοιχεία σου, **ή**
2. Αντίγραψε το `.env.example` σε `.env` και συμπλήρωσε τα `DB_*` (χρησιμοποιούνται μόνο αν δεν υπάρχει το `config/db_config.json`).

Και τα δύο αρχεία αγνοούνται από το git.

### Εκτέλεση

```bash
python main.py
```

ή με διπλό κλικ στο `run.bat`.

Σε καθαρή βάση δημιουργείται προεπιλεγμένος λογαριασμός `admin` (δες το σχόλιο στο `db/schema_consolidated.sql`). **Άλλαξε τον κωδικό μετά την πρώτη σύνδεση.**

### Build (προαιρετικό)

```bash
python build_nuitka.py
```

Παράγει αυτόνομο Windows build με Nuitka· το `build-nuitka/installer_nuitka.nsi` το πακετάρει με NSIS.
